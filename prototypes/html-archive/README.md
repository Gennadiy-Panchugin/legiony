# html-archive — оболочка игры «Легионы» (HTML-прототип)

> PROTOTYPE - NOT FOR PRODUCTION. Одноразовый код; в Unity не переносится.

## Гипотеза

Однофайловая игра-оболочка: карта мира, кампания, постройки, казарма, магазин и библиотека бустов, вокруг которых встроены мультяшные бои из `../art-toon`. Проверялось, можно ли собрать полную мобильную игру одним HTML и встроить в неё бои через iframe.

## Как запустить

- Открыть `legiony.html` в браузере. Собирается из истории правок командой `node embed-war.js` (читает страницы боя из `../art-toon/toonwar`).
- Android: `bash ../legion-flow-concept/android/build.sh` (WebView-оболочка, отладочная подпись).

## Что важно знать, если к этому вернуться

- `legiony.html` не пишется руками: его меняют правки в `embed-war.js` с метками `/*...*/`, повторные запуски идемпотентны только благодаря этим меткам. Старый боевой режим на узлах остался в файле неиспользуемым.
- Обмен с боями идёт сообщениями (`legWar:*`, `legArmy:*`): запас бустов и отметки обучения передаются в бой, расход и «пройдено» возвращаются.
- Подробное описание сделанного к закрытию: раздел «Бой: интерфейс, бусты, тутор, таран, дозор» в `production/HANDOFF.md`.
